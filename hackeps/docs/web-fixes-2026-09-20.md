# Web fixes — 20 September 2026

- Home and waiting page share a responsive SVG scene. Castle, trees and curved
  hills use the same coordinates rather than unrelated viewport heights and
  negative margins. The foreground colour joins the footer without a seam.
- New event registrations initialise all available profile fields; editing an
  existing registration loads the event-specific snapshot, including experience.
  Terms are never accepted automatically. XS is included in shirt sizes.
- Gallery photos are shuffled once per visit and advance every 4.5 seconds.
  Hover, focus and touch interaction pause autoplay; an explicit pause button
  and reduced-motion support keep manual navigation available.
- Profile pictures can only be uploaded from PNG/JPEG/WebP files (1 MiB).
  CV inputs accept PDF (1 MiB); shared client checks validate type, extension,
  byte size and signature. The backend changes must be deployed as well for
  decoding, sanitisation and rejection of active PDF content at the API boundary.
- CV removal is aligned with its input label, with a native file input and
  correct clearing. Profile loading placeholders use the same responsive
  footprint as loaded avatars.
- Membership labels understand UTC timestamps, today and singular units. The
  backend fix computes creation timestamps for each account; it does not infer
  or rewrite historical dates already saved incorrectly.
- The default 2026 schedule has the seven supplied entries: Saturday 28 November
  at 08:30, 10:00, 11:00 and 15:00; Sunday 29 at 11:00, 11:30 and 14:00, shown in
  Europe/Madrid. A configured event programme remains authoritative.
- Unannounced activities say “Sorpresa!”. Sponsor tiers have decreasing logo
  sizes, without tier-name headings; “Col·laboradors” remains a separate final
  section with Supporter-sized logos. Tier 4 editing is handled by the existing
  backend PR #341, not duplicated here.
- Canonicals, sitemap and public links continue to use hackeps.dev; live links
  use live.hackeps.dev, as established by the previous SEO changes.

Validation: 107 frontend tests; full and waiting builds; browser checks with
synthetic API fixtures for registration prefill and delayed mobile profile
loading. Scene screenshots at 320/1280 px and a 1920 px viewport at 67% CSS
scale show consistent layers and no horizontal page overflow. Gallery movement
was observed without input. Backend tests exercise real request validation in
the disposable test database, separately from browser fixtures.
